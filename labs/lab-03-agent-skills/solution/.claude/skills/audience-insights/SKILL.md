# Audience insights
1. Count with code (Python) — never estimate from reading a CSV.
2. Every claim: the count (n) and the file.
3. Label INFERENCE for anything the data does not show directly; LOW
   CONFIDENCE for groups under 20.
4. Quote enquiries verbatim with their ids.
5. Personas: who, worries, channels, formats, trust drivers, gaps.
