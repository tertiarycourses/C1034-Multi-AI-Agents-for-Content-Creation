# Copywriting
1. Name one reader (a persona) and one problem in their words.
2. Use PAS (problem, agitate gently, solve) or AIDA (attention, interest,
   desire, action). Agitate with facts, never fear.
3. Headlines and hooks: write three; pick one and say why. Under 12
   words; specific; no clickbait.
4. One call to action, a verb first ("Download the checklist").
5. Never: promised returns, "guaranteed", urgency that is not real.
