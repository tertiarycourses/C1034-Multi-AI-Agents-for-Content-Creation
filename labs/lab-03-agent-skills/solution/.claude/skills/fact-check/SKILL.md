# Fact-check
1. List every number, age, date, rate, cap or rule in the draft.
2. Match each to data/facts-2026.md: VERIFIED (quote the row) or
   UNVERIFIED.
3. Never correct a figure from memory; UNVERIFIED claims are removed or
   sent to a person.
4. Fees, client returns and "typical" returns are always UNVERIFIED.
