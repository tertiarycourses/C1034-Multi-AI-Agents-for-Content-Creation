# Campaign report
1. From the campaign data, per channel: impressions, clicks, checklist
   downloads, chats booked, spend, cost per chat.
2. Name the cheapest and the most expensive channel per chat.
3. Recommend next month's budget split, with one reason per channel.
4. One page; a table first, then three bullets; no personal data.
