# Landing page
1. Read data/site-brief.md and data/brand.md; copy only approved words.
2. One self-contained HTML page: inline CSS and JS, Google Fonts, inline
   SVG images, no external scripts, no frame-busting, no backend.
3. Sections: hero with one promise, proof from the facts sheet, the offer,
   a form (name, email, a REQUIRED PDPA consent box), FAQ, footer
   disclaimer word for word.
4. Save web/<campaign>/index.html and run page-qa before publishing.
