# Web design
1. Tokens from data/brand.md: colours, Fraunces headings, Nunito body,
   a type scale (e.g. 16 / 20 / 28 / 40px).
2. Mobile first: one column at 375px, 44px tap targets, no horizontal
   scroll; widen to a grid at 1024px+.
3. Contrast at least WCAG AA; visible focus; real headings in order.
4. One primary button per screen; whitespace leads the eye to the call
   to action.
5. Inline SVG and compressed images; the page loads without a backend.
