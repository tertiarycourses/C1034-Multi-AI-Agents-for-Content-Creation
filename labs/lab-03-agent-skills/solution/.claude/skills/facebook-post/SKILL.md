# Facebook post
1. 60-150 words, warm and local — a neighbour, not a banker.
2. One everyday situation (HDB, CPF, a family moment) and one tip.
3. End with a question that invites a comment.
4. An image brief for the Creative Designer: headline (the hook),
   1080 x 1080, the Horizon look, key words, alt text. Put the alt
   text in the post's alt: line.
5. The UTM link (?utm_source=facebook&utm_medium=social&utm_campaign=
   <campaign>), the Sunny sign-off and the short disclaimer.
6. The Creative Designer's image (1080 x 1080 PNG beside the post) with
   the image: and alt: lines filled in.
