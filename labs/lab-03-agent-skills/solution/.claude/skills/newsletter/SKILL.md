# Newsletter (Sunny Sunday)
1. Follow data/newsletter-spec.md. Subject under 50 characters; preview
   text under 90.
2. One tip, one nudge, one call to action — scannable on a phone.
3. Every link carries utm_medium=email.
4. Build newsletter.html and a plain-text newsletter.txt from the
   APPROVED issue only.
5. Footer: unsubscribe link, postal address, short disclaimer.
6. Recipients: consent = yes and unsubscribed = no — nobody else.
