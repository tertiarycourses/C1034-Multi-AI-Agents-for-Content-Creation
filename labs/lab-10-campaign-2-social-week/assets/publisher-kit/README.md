# Publisher kit (Claude edition)

Already installed in your horizon-studio folder — nothing to copy. This is a spare copy.

- **Approve** by typing in Claude Code: `approved <id> by <your name>` — or send it back: `changes <id>: what to fix`. Only your own message can approve; agents cannot.
- **The gate** stops agents approving, editing the approval records, or publishing anything that is unapproved or changed since you approved it.
- **Publishing** is a dry run unless you connect real accounts (connect-accounts.md) and say "go".
